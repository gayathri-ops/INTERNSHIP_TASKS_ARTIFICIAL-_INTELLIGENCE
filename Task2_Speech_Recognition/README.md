# Voice2Text AI Transcriber

## Project Overview

Voice2Text AI Transcriber is a Speech Recognition System developed as part of the CODTECH Artificial Intelligence Internship. The project converts spoken language into text using Artificial Intelligence and Natural Language Processing techniques.

The system captures audio input through a microphone and transcribes it into readable text using Google's Speech Recognition engine.

---

## Objective

The main objective of this project is to develop a basic Speech-to-Text application capable of recognizing human speech and converting it into textual format accurately.

---

## Technologies Used

* Python
* SpeechRecognition Library
* Google Speech Recognition API
* PyAudio

---

## Features

* Real-time speech recognition
* Converts voice input into text
* User-friendly implementation
* Supports microphone-based input
* Fast and accurate transcription

## Installation

Install the required libraries using:

pip install SpeechRecognition

pip install PyAudio

---

## How to Run

1. Open Command Prompt.
2. Navigate to the project folder.
3. Execute the following command:

py app.py

4. Speak clearly into the microphone.
5. The recognized text will be displayed on the screen.
