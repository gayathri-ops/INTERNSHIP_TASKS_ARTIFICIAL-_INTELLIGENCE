# AI Artistic Vision Engine

## Objective

This project applies artistic styles to photographs using Neural Style Transfer and deep learning techniques.

## Technologies Used

* Python
* TensorFlow
* TensorFlow Hub
* Pillow

## Features

* Applies artistic styles to photographs.
* Uses a pre-trained Neural Style Transfer model.
* Generates stylized output images automatically.

## How to Run

1. Place content.jpg and style.jpg in the project folder.
2. Execute:
   py app.py
3. View output.jpg.

## Applications

* Digital Art
* Creative Design
* Photo Enhancement
* AI-based Image Processing
