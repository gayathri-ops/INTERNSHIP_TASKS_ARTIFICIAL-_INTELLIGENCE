# PromptCraft AI Writer

## Objective

This project generates coherent text paragraphs based on user prompts using a pre-trained GPT model.

## Technologies Used

* Python
* Hugging Face Transformers
* GPT-2
* PyTorch

## Features

* Accepts user prompts.
* Generates AI-written paragraphs.
* Uses a pre-trained language model.
* Demonstrates Generative AI concepts.

## How to Run

1. Install dependencies.
2. Execute:
   py app.py
3. Enter a topic.
4. View generated content.

## Applications

* Content Creation
* Blogging
* Story Writing
* Idea Generation
