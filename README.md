# CODTECH Artificial Intelligence Internship

## Overview

This repository contains all the tasks completed during the CODTECH Artificial Intelligence Internship. The projects demonstrate practical applications of Artificial Intelligence, Machine Learning, Natural Language Processing, Speech Recognition, Generative AI, and Computer Vision.

The internship focuses on developing real-world AI solutions using Python and modern AI frameworks.

---

## Internship Tasks

### Task 1 – Smart Article Condenser Using NLP

A text summarization system that converts lengthy articles into concise summaries using Natural Language Processing techniques and Transformer-based models.

#### Technologies Used

* Python
* Transformers
* PyTorch
* NLP

#### Features

* Reads long articles
* Generates concise summaries
* Uses pre-trained Transformer models

---

### Task 2 – Voice2Text AI Transcriber

A Speech Recognition System that converts spoken language into text using AI-powered speech processing.

#### Technologies Used

* Python
* SpeechRecognition
* PyAudio
* Google Speech Recognition API

#### Features

* Real-time speech recognition
* Microphone-based input
* Accurate speech-to-text conversion

---

### Task 3 – AI Artistic Vision Engine

A Neural Style Transfer application that combines the content of one image with the artistic style of another image.

#### Technologies Used

* Python
* TensorFlow
* TensorFlow Hub
* Pillow

#### Features

* Artistic image generation
* Neural Style Transfer
* Deep Learning based image processing

---

### Task 4 – PromptCraft AI Writer

A Generative AI application that creates meaningful paragraphs from user-provided prompts using GPT-based language models.

#### Technologies Used

* Python
* Transformers
* GPT-2
* PyTorch

#### Features

* AI-powered text generation
* Prompt-based content creation
* Context-aware paragraph generation
