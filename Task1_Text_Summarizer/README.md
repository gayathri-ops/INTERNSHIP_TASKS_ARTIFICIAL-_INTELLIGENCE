# Smart Article Condenser Using NLP

## Objective

This project is developed as part of the CODTECH Artificial Intelligence Internship. The objective is to summarize lengthy articles into concise and meaningful summaries using Natural Language Processing techniques.

## Technologies Used

* Python
* Hugging Face Transformers
* PyTorch
* NLP

## Features

* Reads lengthy text from a file.
* Generates concise summaries automatically.
* Uses a pre-trained DistilBART model.
* Easy to use and scalable.

## How to Run

1. Install required libraries.
2. Place article content in article.txt.
3. Execute:
   py app.py

## Output

The system displays the original article and generates a summarized version automatically.
